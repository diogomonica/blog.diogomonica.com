# blog.diogomonica.com

Static blog for Diogo Monica, migrated from Ghost to Astro.

See package.json scripts for dev and build.

Cloudflare Pages: Astro preset, build via package.json build script, output dist, custom domain blog.diogomonica.com.
Post URLs: /YYYY/MM/DD/slug/.

Build: npm run build. Output: dist.

Image variants (AVIF/WebP) are generated by `npm run images` and committed under `public/`. The build checks that they are current and does not re-encode them, so Cloudflare Pages does not need sharp's native binary. After adding or replacing an image, run `npm run images` and commit the new files plus `src/data/image-variants.json`. Original `/content/images/...` URLs stay in place.
